## Findings
- [follow-up] src/broker/windows.rs:305-309 (`ObjectSecurity::dacl`) with src/broker/windows.rs:527-533 (`only_broker_writes`): a NULL DACL, which grants everyone full access, is returned as an empty `aces` list. `only_broker_writes` then accepts it if the protected bit is set, because `all()` over no ACEs is true. Only the folder's owner (the Broker or Administrators) could set such a DACL, and Administrators are out of scope (ADR-0004), so a user cannot exploit this today. → A later job should make `Dacl` tell a NULL DACL apart from an empty one (for example `aces: Option<Vec<Ace>>`) and have `only_broker_writes` refuse a NULL DACL.
